# Gửi mẹ ngày 20/10

Trang web tặng mẹ nhân ngày 20/10: cổng mở, tạo bó hoa mười bông, bức thư và thiệp lời chúc.

## Cách chạy

- Mở thư mục này trong VS Code, cài tiện ích Live Server, bấm chuột phải vào index.html rồi chọn Open with Live Server.
- Hoặc mở thẳng index.html bằng trình duyệt.
- Cần có mạng để tải phông Lora. Không có mạng, trang tự dùng phông Georgia.

## Cấu trúc

- index.html: khung trang (cổng, bó hoa, thư, thiệp)
- style.css: toàn bộ giao diện
- script.js: các loại hoa, vòm hoa, hiệu ứng và lời chúc

## Sửa lời chúc

Mở script.js, sửa mảng LOI_CHUC (mỗi dòng là một đoạn) và KY_TEN ở đầu file.
